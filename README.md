### 🌟 Featured Projects
#### 🎬 1. [Cinema Booking Agent](https://github.com/GiaBaoIT27/cinema-booking-agent) *(Monorepo · NestJS · Next.js 16 · React Native · AI Agent)*
> Nền tảng đặt vé xem phim trực tuyến đa kênh (Web + Mobile), tích hợp Trợ lý ảo AI đàm thoại qua SSE.
- **High-Concurrency:** Chống race condition đặt trùng ghế bằng **Distributed Locking (Redlock over Redis)**; quản lý hàng đợi hủy vé quá hạn với **BullMQ**.
- **Backend Architecture:** Thiết kế chuẩn **Domain-Driven Design (DDD)** 4 tầng, đạt **100% pass với 32 unit tests Vitest**.
- **Modern Client Tier:** **Next.js 16 (React 19)** với App Router, TanStack Query v5, Zustand, React Leaflet GIS; và **React Native / Expo Router v3** trên iOS/Android.
- **AI-Native:** Xây dựng Stateful Graph Agent bằng **LangGraph** + **Gemini API** streaming thời gian thực.
#### 🚦 2. AST-Net: Traffic Forecasting & Visualization Platform *(Graduation Thesis)*
> Hệ thống giám sát và dự báo lưu lượng giao thông thời gian thực trên mạng lưới hơn 200 cảm biến GIS.
- **Frontend Dashboard:** Xây dựng bằng **Next.js 14**, tích hợp **Leaflet GIS** và **Apache ECharts** vẽ biểu đồ chuỗi thời gian 12 bước ($15', 30', 45', 60'$).
- **Inference REST API:** Backend **FastAPI** phục vụ suy luận mô hình học sâu Spatio-Temporal PyTorch với độ trễ **sub-150ms**.
